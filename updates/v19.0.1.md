# v19.0.1 — 07.10.2026

Grundlage: Repo-Stand `42baae3` (19.0.0).

Bugfix, keine Datenbankänderung.

## Was wurde geändert und warum

Rückmeldung aus Greifswald: Beim Speichern unter Mehr → Rad-Nummern kam
„Could not find the function public.rad_nummern_setzen … in the schema
cache“. Die Data API kennt die neue Funktion noch nicht. Ursache: Die
Migration 19.0.0 ist in Neon nicht gelaufen, oder der Schema-Cache wurde
danach nicht neu geladen. Das ist kein Fehler im Code, aber zwei Dinge in
der App waren dabei unschön:

- **Vorschau zeigte nach dem Fehler alte Eingaben.** Beim Neuzeichnen las
  die Vorschau noch die alten Felder (z. B. HSG-TR / 4), während die Felder
  schon wieder den gespeicherten Stand zeigten (leer / 2). Jetzt zeigt die
  Vorschau beim Zeichnen den gespeicherten Stand und beim Tippen die
  Eingabe.
- **Englische Meldung.** Fehlt der Datenbank eine Funktion, sagt die App
  jetzt auf Deutsch, welche Funktion fehlt und was zu tun ist: Migration
  ausführen, danach „Refresh schema cache“.

1. Neon → SQL-Editor → `db/migration_19.0.0.sql` ausführen.
2. Neon → Data API → „Refresh schema cache“.
