# v5.3.0 — 01.10.2026

Grundlage: Repo-Stand `a376e45` (5.2.0). Ausgeliefert zusammen mit 5.3.1.

## Was wurde geändert und warum

### Inventur „Alles auf einmal“
Bisher wurde je Inventur ein Ort gezählt (Werkstatt, Koffer Bahn, Koffer
Straße). Jetzt gibt es beim Start als erste Wahl **„Alles auf einmal“**.

- **Zählstellen:** Jeder Artikel hat eine Zeile für die Werkstatt. Eine
  Zeile für einen Koffer kommt nur dazu, wenn der Artikel dort ein Soll
  hat oder dort etwas liegt. So bleibt die Liste kurz.
- **Je Zählstelle** stehen dort der Systembestand und „zuletzt gezählt“,
  dazu ein eigenes Zählfeld mit ✓.
- **Bedienung:** Enter springt zum nächsten Feld, auch zwischen den Orten
  eines Artikels. Fortschritt, Filter („Noch offen“, „Abweichung“),
  Buchstaben-Auswahl und Scannen funktionieren wie bisher. Beim Scan
  springt die App auf das erste Feld des Artikels.
- **Übernehmen:** Die Zusammenfassung zeigt die Abweichungen mit Ort.
  Gebucht wird je Ort, jeweils mit eigener Kennung. Bricht die Verbindung
  mittendrin ab und man drückt erneut auf „Buchen“, werden bereits
  gebuchte Orte nicht noch einmal gebucht.
- **Bewegungen während der Inventur** bleiben wie bisher erhalten.
  Korrigiert wird nur die Abweichung zum Zeitpunkt des Zählens.

Die Inventur für einen einzelnen Ort funktioniert unverändert. Eine
angefangene, noch nicht übernommene Inventur aus 5.0–5.2 wird beim ersten
Öffnen übernommen.

## Geprüft

Im Browser gegen eine lokale Datenbank:
- Auswahl „Alles auf einmal“; Koffer-Zeilen nur bei Soll oder Bestand.
- Enter-Sprung über die Orte eines Artikels, ✓ in einer Koffer-Zeile.
- Zusammenfassung mit Ort. Gebucht wird je Ort: drei Inventur-Läufe,
  Korrektur im Koffer Bahn, Zählzeitpunkte je Ort gespeichert.
- Übernahme eines angefangenen Entwurfs im Format von 5.2.
- Handyansicht per Bildschirmfoto geprüft.

## Bekannte offene Punkte

- Liegt etwas in einem Koffer, für den es kein Soll gibt und der Bestand
  laut System 0 ist, erscheint dafür keine Zählstelle. Solche Funde über
  die Einzel-Inventur im Artikelmenü oder eine Inventur nur für diesen
  Koffer erfassen.
