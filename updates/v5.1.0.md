# v5.1.0 — 01.10.2026

Grundlage: Repo-Stand `0256601` (5.0.1).

## Was wurde geändert und warum

### Einzelstücke als Serie anlegen
Mehrere gleiche Teile ohne Nummer, z. B. vier gleiche Laufräder, mussten
bisher einzeln angelegt werden.

- **Feld „Anzahl gleicher Teile“:** neu im Formular „Neues Einzelstück“,
  Standard 1.
- **Vorschau:** Bei mehr als 1 zeigt sie den Bereich, z. B. „wird
  voraussichtlich L-202 bis L-205“.
- **Speichern:** legt alle Stücke in einem Schritt mit fortlaufenden
  Nummern an. Typ, Marke, Detail, Kaufdatum und Notiz werden für alle
  übernommen. Es entstehen alle oder keines, auch bei
  Verbindungsabbruch.
- **Seriennummer:** Bei mehreren Stück ist das Feld gesperrt, weil jedes
  Teil eine eigene hat. Sie wird später je Stück über „Details
  bearbeiten“ eingetragen.
- **Grenzen:** höchstens 50 auf einmal, nur mit automatischer Nummer.

Tipp: Vorder- und Hinterräder getrennt anlegen („Laufrad Bahn vorne“ × 4,
dann „hinten“ × 4). So ist auf dem Etikett eindeutig, welches Teil
welches ist.

### Feld „Wert“ entfernt
Das Feld „Wert (€)“ ist aus dem Einzelstück-Formular entfernt, weil es an
dieser Stelle nicht gebraucht wird.

- Bereits eingetragene Werte bleiben in der Datenbank erhalten und werden
  beim Bearbeiten nicht überschrieben.
- Im Export „Einzelstücke“ steht die Spalte weiterhin.

## Manuelle Schritte

1. Neon SQL-Editor: alles im Editor löschen, den gesamten Inhalt von
   `db/migration_5.1.0.sql` einfügen, **Run**.
2. Data API → **Refresh schema cache**.
3. Die Dateien hochladen, App neu laden, unten muss „Version 5.1.0“
   stehen.

Die alte App (5.0.1) läuft mit der ergänzten Datenbank unverändert weiter.

## Geprüft

- Migration auf 5.0.0 und Neuinstallation mit `schema.sql` ergeben exakt
  dieselbe Struktur (Vergleich per `pg_dump`).
- Funktion als anonymer Nutzer: 4 Stück mit fortlaufenden Nummern; eine
  ungültige Anzahl wird abgelehnt.
- Im Browser:
  - Vorschau des Bereichs, gesperrte Seriennummer, Anlegen von 4 Stück.
  - Bearbeiten eines Stücks mit Wert: der Wert bleibt erhalten.
  - Anzahl mit eigener Nummer wird abgelehnt.

## Bekannte offene Punkte

- Die Spalte `wert` bleibt in der Datenbank. Wird sie nie gebraucht, kann
  sie in einer späteren Version entfernt werden.
