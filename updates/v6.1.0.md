# v6.1.0 — 01.10.2026

Grundlage: Repo-Stand `ec6d883` (5.3.1). Ausgeliefert zusammen mit 5.3.2,
5.4.0, 6.0.0 und 6.2.0. Die Auswahl im Formular wurde in 6.2.0 noch einmal
umgebaut (eine gemeinsame Liste statt zwei Felder).

## Was wurde geändert und warum

Mit 6.0.0 entstand ein Einzelstück-Ticket nur, wenn man im Inventar den
Zustand ändert. Jetzt geht auch der umgekehrte Weg.

### „+ Neues Ticket“ mit Einzelstück
- **Neues Feld „Einzelstück (optional)“** unter dem Rad, mit Scan-Knopf.
  - Ist ein Rad gewählt, stehen dessen Teile oben („An diesem Rad“),
    darunter die losen.
  - Ausgemusterte Teile erscheinen nicht.
- **Teil steckt an einem Rad:** Das Rad wird automatisch übernommen.
- **Loses Teil** (z. B. Laufrad in der Werkstatt): Ein Rad ist nicht
  nötig, die Frage „Rad noch fahrbereit?“ entfällt.
- **Scannen:** Der Scan-Knopf beim Rad erkennt auch Nummern von
  Einzelstücken.
- **Bestehendes Ticket:** Gibt es für das Teil schon ein offenes Ticket,
  steht ein Hinweis darunter.
- **Ohne Rad und ohne Teil** lässt sich kein Ticket anlegen.

### Automatisch „zu prüfen“
- Beim Anlegen eines Tickets mit Einzelstück setzt die Datenbank das Teil
  von „frei“ auf **„zu prüfen“**, im selben Schritt wie das Anlegen.
- „defekt“ bleibt „defekt“.
- Wie bisher lässt sich das Ticket erst abschließen, wenn das Teil im
  Ticket freigegeben ist.

## Manuelle Schritte

1. Neon SQL-Editor: alles löschen, den gesamten Inhalt von
   `db/migration_6.0.0.sql` einfügen, **Run**.
2. Editor leeren, den gesamten Inhalt von `db/migration_6.1.0.sql`
   einfügen, **Run**.
3. Data API → **Refresh schema cache**.
4. Alle Dateien hochladen (zusammen mit 6.2.0).

## Geprüft

- **Datenbankstruktur:** Die Kette 5.2.0 → 6.0.0 → 6.1.0 und eine
  Neuinstallation mit `schema.sql` ergeben exakt dieselbe Struktur
  (Vergleich per `pg_dump`).
- **Im Browser gegen eine lokale Datenbank:**
  - loses Teil ohne Rad (Ticket ohne Rad, Teil → „zu prüfen“)
  - Scan eines Teils am Rad (Rad übernommen, „Rad steht“, Teil → „zu
    prüfen“)
  - defektes Teil bleibt „defekt“
  - Rad gewählt: Teile am Rad stehen oben; ein Ticket nur mit Rad geht
    wie bisher
  - ohne Rad und ohne Teil wird abgelehnt
