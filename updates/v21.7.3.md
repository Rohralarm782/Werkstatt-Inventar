# 21.7.3 — 21.11.2026

**Grundlage:** Commit `596956b` (21.7.2)

## Was wurde geändert und warum
- GitHub hat Node 20 für Actions abgeschaltet. Die bisher verwendeten
  Action-Versionen liefen noch auf Node 20 und wurden von GitHub zwangsweise
  unter Node 24 ausgeführt (Warnung in jedem Lauf). Jetzt werden die
  aktuellen Versionen verwendet, die selbst auf Node 24 laufen:
  - `veroeffentlichen.yml`: checkout v4 → v7, configure-pages v5 → v6,
    upload-pages-artifact v3 → v5, deploy-pages v4 → v5
  - `push-morgen.yml`: checkout v4 → v7, setup-node v4 → v7
- `push-morgen.yml`: `package-manager-cache: false` bei setup-node, damit kein
  automatischer npm-Zwischenspeicher angelegt wird (der Lauf hat Zugriff auf
  die Secrets; Zwischenspeicher wird nicht gebraucht).
- upload-pages-artifact lässt ab v4 versteckte Dateien (Name beginnt mit
  Punkt) weg. Außer `.git` und `.github` gibt es keine im Repo, die
  veröffentlichte App ist also unverändert.
- Anlass: Der nächtliche Lauf am 21.11. ist gescheitert („No artifacts named
  github-pages“ / „Fetching artifact metadata failed“). Das war ein
  vorübergehender Fehler bei GitHub (das Paket war hochgeladen), nicht die
  Ursache für dieses Update — das Update räumt nur die Node-20-Warnung auf.
- App-Code unverändert; nur Versionsnummer.
